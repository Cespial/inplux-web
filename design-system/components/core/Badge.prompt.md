Small pill tag for categories, statuses and meta. Outline by default; soft-teal for emphasis. Use `uppercase` for tracked eyebrow-style tags.

```jsx
<Badge variant="soft">IA tributaria</Badge>
<Badge variant="outline" uppercase>NIC/NIIF</Badge>
<Badge variant="onDark">Estatuto vivo</Badge>
```

Variants: `outline`, `soft` (teal-soft fill), `teal`, `ink`, `onDark` (for dark sections).
