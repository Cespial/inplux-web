Warm white card surface — hairline border, 14px radius, lifts 2px on hover. The base container for products, features, blog cards.

```jsx
<Card>
  <Eyebrow>Producto</Eyebrow>
  <h3>Tribai.co</h3>
  <p>Inteligencia tributaria que aprende.</p>
</Card>
```

Props: `hover` (default true), `padding` (default 2rem), `as`. Set `hover={false}` for static panels.
