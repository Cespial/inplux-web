# UI Kit — INPLUX marketing website

Recreation of **inplux.co**, the marketing site for INPLUX S.A.S., built on the
Editorial White System v3. This is the company's primary public surface.

## What it shows
A single scrolling homepage (`index.html`) composed of:
- **Nav** — frosted sticky header (blur + saturate), gains a hairline border + shadow on scroll. Mobile burger menu.
- **Hero** — dark ink section: serif headline with one *italic teal* word, lead paragraph, teal + ghost CTAs, authority pills (+25 años · +50 municipios · +100 proyectos), and the signature `OrbitGraphic`. Dotted texture + teal radial glow.
- **Allies** — quiet logo/word strip on off-white.
- **Ecosystem** — 3-col product grid (Tribai.co star + Gobia, Fourier, Aries, Think IT, Observatorio) using `Card` + `Badge`.
- **Pillars** — the 3 philosophy statements, big serif numerals.
- **StatsBand** — dark metric band (`Stat`).
- **CTA / Contact** — "Hablemos" form with success state.
- **Footer** — dark, ecosystem + contact columns.

## Interactivity
- Sticky nav scroll state; mobile menu toggle.
- "Hablemos" buttons smooth-scroll to the contact form (manual `scrollTo`, not `scrollIntoView`).
- Contact form submits to an inline success state.

## Built from
The brand kit (`uploads/INPLUX-brand-kit.zip`) + the live-site reference frame
(`assets/reference/og-image-actual.png`). No live codebase/Figma was attached, so
section composition is a faithful reconstruction of the documented system rather than a
line-for-line copy of the production DOM.

## Components used
`Nav`, `Hero`, `Allies`, `Ecosystem`, `Pillars`, `StatsBand`, `CTA`, `Footer`
(`sections.jsx`) — each composing DS primitives (`Button`, `Card`, `Badge`, `Pill`,
`Stat`, `Eyebrow`, `Logo`, `OrbitGraphic`, `Input`, `Field`) from the compiled bundle.

> The bundle (`_ds_bundle.js`) is regenerated by the compiler; open `index.html` after a
> compile so `window.INPLUXDesignSystem_318bee` is populated.
